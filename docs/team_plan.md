# Team plan (4 people)

The deadline isn't fixed here, so the plan uses **weeks from start (W1-W10)**. If you have less
time, compress W8-W10. Never cut the controls; cut the bonus instead.

## Roles

Each person **owns** one part (makes the decisions, runs it, writes that section) and **reviews**
another (reads the code, re-runs one number, checks the logic). Reviewing is what catches bugs.

| Person | Owns | Reviews | Report sections |
|---|---|---|---|
| **P1 - Data lead** | sandbox, minimal pairs, dataset build, data card, QC annotator A | P4's tasks | Method: labelling, sandbox, dataset; data card |
| **P2 - Environments lead** | ScienceWorld labeller, ToolEmu sheet, QC annotator B, RQ5 | P1's labels | Method: ScienceWorld; RQ5; Limitations |
| **P3 - Probing lead** | GPU setup, smoke test, hidden states, probes, baselines, ablations, RQ2 comparison | P2's ScienceWorld data | Method: probes, stated; Results RQ1, RQ2 |
| **P4 - Agent lead** | agent tasks, agent runs, K, gap analysis, steering (RQ4), demo | P3's probes | Method: behaviour, gap, steering; Results RQ3, RQ4 |

**Everyone:** Group A reading in W1; Introduction, Discussion and Conclusion together in W9;
the final read-through.

**Group B reading split** (one-page summary each, presented to the team in W2):
- P1: Krakovna et al.; Turner et al.
- P2: SafeAgentBench (note which arXiv version); Wang et al. world simulators
- P3: Othello-GPT; Rimsky et al. (CAA)
- P4: Tang et al. (closest work: read it very carefully); Schmied et al.

## Compute budget (rough; measure your own in W2-W3)

| Job | Approx. cost per model |
|---|---|
| Hidden states, ~2,000 pairs | minutes (one forward pass each) |
| Probes, all layers, 3 splits, all ablations | CPU, about 1-3 h total |
| Stated answers, ~2,000 short generations | ~15-30 min |
| Agent, 130 episodes x up to 15 steps | ~1-2 h per prompt condition |
| Steering, 7 strengths x (1 probe + 3 random) directions | ~25-50 h: start early, or first run only the irreversible versions and 1 random direction |
| ScienceWorld labelling | depends on replay speed; pilot first, use `--workers` |

- Tag the frozen dataset (`v1-data`) and the pre-registration commit.
